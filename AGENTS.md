## Agent skills

### Issue tracker

Issues and specs live in local Markdown under `.scratch/<feature>/`.
Read `docs/agents/issue-tracker.md` before creating, fetching, or updating tickets.

### Triage labels

Use the five default triage roles as local issue statuses.
Read `docs/agents/triage-labels.md` before triaging tickets.

### Domain docs

Use single-context domain docs: root `GLOSSARY.md` and `docs/adr/`.
Read `docs/agents/domain.md` before exploring the codebase.
