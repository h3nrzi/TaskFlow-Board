# Triage labels

For local issues, record the role in a `Status:` line near the top.

| Canonical role | Local status | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer needs to evaluate the issue |
| needs-info | needs-info | Waiting on the reporter for information |
| ready-for-agent | ready-for-agent | Fully specified and ready for an agent |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be actioned |

When a skill requests a triage label, use the corresponding local status.
Wayfinding lifecycle statuses are defined separately in `issue-tracker.md`.
